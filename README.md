# Hana Guo Interactive Portfolio

本資料夾可直接部署至 GitHub Pages。

1. 將資料夾內所有檔案上傳至 GitHub repository 根目錄。
2. 前往 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/(root)`。
5. 儲存後等待 GitHub Pages 產生網址。

請保留 `index.html`、`assets`、`hana-profile.png`、`og.png` 與 `resume.pdf` 的相對位置。

注意：網站公開後，履歷 PDF、照片與 Email 也會公開。
